## 一、30 秒上手

1. **打开链接** —— https://javenzheng.github.io/mcd-diet-buddy/ 。手机、电脑均可；数据全部内联在单文件网页里，不连后端、无需登录、无需 token。
2. **选择预算** —— 页面顶部有三档：1200 / 1500 / 1800 kcal，选一个你今天的目标。
3. **转转盘或选套餐** —— 想吃什么就点「今日食咩」转盘，或者在「点食先减肥卡」里选一个套餐，程序会直接给出结果。

整个网页只有 **2 个决策点**：预算 + 主食，其余全部自动配好。

## 二、功能一：今日食咩（转盘）

> 说明：「今日食咩」「点食先减肥卡」「揾门店」是网页上的三个功能名，沿用粤语口语（意为「今天吃什么」「怎么吃才减肥」「找门店」），方便与实际界面对照，下文不再逐字翻译。

**做什么**：给定一个热量预算，帮你配好一日三餐，每餐附改造建议。

**怎么用**：
1. 选择预算（1200 / 1500 / 1800 三档）。
2. 点「转」，转盘停在哪个主食上，就围绕它配齐早餐、午餐、晚餐。
3. 不满意可以再转一次，也可以手动更换主食。

**你会看到**（以预算 1500、转中巨无霸为例，均为实际运行输出）：

| 餐次 | 配搭 | 热量 | 蛋白 | 改造建议 | 改造后 |
|---|---|---|---|---|---|
| 早餐 | 烟肉蛋麦满分 + 小杯玉米杯 + 纯悦 | 313 | 18 g | 玉米杯换苹果片，省 21 卡 | 292 |
| 午餐 | 巨无霸 + 大杯玉米杯 + 冰美式小杯 | 610 | 32 g | 去吉士 −60、玉米杯换苹果片 −55、去巨无霸酱 −50 | 427 |
| 晚餐 | 麦乐鸡5块 + 小薯条 + 冰美式大杯 | 437 | 16 g | 小薯条换苹果片，省 178 卡 | 259 |

**全天合计 1360 kcal｜蛋白质 66 g（下限 60）｜钠 1989 mg（上限 2000）｜无预警。**

**四条硬约束**（超标会主动提醒，不会静默略过）：
- 全天钠 ≤ 2000 mg，单餐钠 ≤ 1100 mg
- 蛋白质下限 = 热量 ÷ 25
- 每餐设有热量下限——**不会出现「早餐只给你一杯饮料」的情况**
- 自动过滤派、大薯条、麦旋风、含糖饮料，并说明「这些我帮你过滤掉了」及原因；**无糖可乐、玉米杯不会被误杀**

## 三、功能二：点食先减肥卡（作品核心）

**做什么**：给定一个官方套餐，列出**官方自己支持**的改造动作，逐项标明能省多少卡、要不要加钱。

**怎么用**：
1. 选择一个套餐（内置 **12 个真实在售官方套餐**：8 个三件套 + 2 个四件套 + 官方 500 大卡线套餐 + 炸鸡套餐）。
2. 点「一键帮我减肥」，全部开关自动打开。
3. 不喜欢可以逐个关闭——每个开关都写明了能省多少卡及其数据级别。

**门面案例（巨无霸三件套，数字全部为实际计算）**：

| 轮次 | 改造前 | 改造动作 | 改造后 | 省 | 数据级别 | 价格差 |
|---|---|---|---|---|---|---|
| 小食 | 中薯条 289 | → 小杯玉米杯 | 53 | **−236** | 🅰️ 官方替换 | −¥0.5 |
| 饮料 | 可乐中杯 147 | → 无糖可口可乐中杯 | 0 | **−147** | 🅰️ 官方替换 | ¥0 |
| 主食 | 巨无霸 513 | 去吉士 + 去巨无霸酱 | — | **−110** | 🅱️ 官方支持·估算 | ¥0 |

**949 → 456 kcal，省 493 卡（-51.9%）。**

12 个套餐中降幅最大的是**麦香鱼套餐：761 → 258 kcal（省 503，-66.1%）**。
另有**酥脆无双套餐省 0 卡**——它本身就是官方「500 大卡套餐」，已经达标，**不是漏算**，页面已如实标注。

## 四、功能三：找门店

**做什么**：查询附近官方门店，逐家比对「这家店有没有这个套餐、卖多少钱」。

**怎么用**：选择城市（广州 / 深圳 / 上海 / 北京，共 20 家门店）→ 查看门店列表 → 点开看该店的在售套餐与**门店价**（不同门店价格会不同）。

**两个如实告知的官方限制**：
- 官方接口**不返回门店精确经纬度**，所以显示的距离是相对查询地标的距离，不是相对你当前位置的距离（已标注为 C 级估算）。
- 官方接口**在门店非营业时间会报错**，拉不到菜单的门店会标注「未预载菜单」，**不会用其他门店的数据顶替**。

## 五、数据严谨性（A / B / C 三级）

- **🅰️ A 级** —— 官方营养数值 / 官方替换选项 / 官方特调动作。例：中薯条 289 kcal、可乐换无糖 ¥0。
- **🅱️ B 级** —— 动作由官方支持，但热量变化没有官方数值，采用估算并**明确标注为估算**。例：去吉士官方有开关，但能减多少卡官方没有给出数值。
- **🅲️ C 级** —— 完全没有官方数据的经验估算，**一律以区间形式给出并明示「估算」**。例：只吃馅不吃面包胚，估算省 80–130 卡。

营养数值**全部来自麦当劳官方 MCP**，不使用记忆数值；餐品名匹配不上官方营养表时**原样列出**，不会找一个相似名称顶替当数。

## 六、技术实现（简述）

调用麦当劳官方 MCP 的 4 个能力：`list-nutrition-foods`（官方营养表）、`query-meal-detail`（**套餐结构**：轮次 / 可换选项 / 能否去配料）、`query-nearby-stores`（门店）、`query-meals`（门店菜单与门店价）。

改造引擎读取的是官方 `rounds[] + choices[] + modification[]` 结构——**每一个「改造动作」都能对应回官方接口的某一行字段**。这是它与「自己写一份经验改造清单」最大的差别。
详见仓库 `MCP_INTEGRATION.md`。

## 七、常见问题

**Q：需要安装 App / 登录 / 提供 token 吗？**
不需要。单文件网页，数据内联，直接打开链接即可使用。

**Q：手机上能用吗？**
能，采用移动端优先设计，转盘点触即可。

**Q：这些数字准不准？**
营养数值全部来自麦当劳官方 MCP，以官方为准；实际出品以门店为准。B / C 级估算均已在页面标明。

**Q：我是肾病 / 糖尿病 / 孕妇人群，可以用它作为饮食依据吗？**
不可以。本作品仅为减脂期的日常参考，**不是医疗或营养处方**，钠摄入与减脂安排请遵医嘱。
