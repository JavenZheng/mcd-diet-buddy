> 目标：评委睇完就明「做咩、点解咁做、点用」。评分维度「展示」占 20%，官方建议 **3 分钟讲清做了什么、为什么做、下一步**。
> 规格：mp4（H.264 保证在线播放）· 500 MB 以内 · 建议 1080p 横屏 16:9。
> 录之前：关掉通知、浏览器全屏、地址栏留白（唔好 expose 私人书签）。

## 录之前嘅 checklist

- [ ] 浏览器**全屏**（F11 / ⌘+Ctrl+F），1080p，横屏
- [ ] 开「勿扰模式」，关通知；关掉其它标签页
- [ ] 录之前先自己**完整跑一次**（转盘停边个主食都唔紧要，数字会变但结构一样）
- [ ] 录音用耳机麦，环境静；语速比平时慢一档
- [ ] 数字位**要停顿**（949 → 456 呢下停 1 秒，畀评委睇清）
- [ ] 导出 **mp4 / H.264**，确认 ≤ 500 MB

## 唔好做

- 唔好 expose 私人书签栏 / 微信 / 邮箱通知
- 唔好讲「我估」「应该系」——数字全部有官方出处，讲「官方接口返返嚟嘅」
- 唔好超过 3 分钟（超出部分评委未必睇）
